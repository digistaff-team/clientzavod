## 1. Что потребуется перед стартом

Перед началом подготовьте следующие данные в зависимости от каналов, которые вы планируете подключить:

| Канал | Что нужно подготовить |
|---|---|
| **Telegram** | ID вашего Telegram-канала (формат `-100...`), Telegram ID модератора |
| **ВКонтакте** | Токен VK API, ID группы VK |
| **Instagram** | Токен Buffer API, Instagram-аккаунт в Buffer |
| **Pinterest** | Токен Buffer API, Pinterest-доска |
| **YouTube** | Токен Buffer API |
| **TikTok** | Учётные данные TikTok |
| **Одноклассники** | Токен OK API |
| **Facebook** | Facebook App токен |
| **WordPress** | URL блога, логин/пароль WordPress |
| **Все каналы** | Телефон с Telegram-приложением (для верификации) |

> **Telegram всегда подключён по умолчанию.** Остальные каналы подключаются опционально.

## Шаг 1 — Регистрация и вход

### 1.1 Откройте Auth Bot в Telegram

1. Найдите в Telegram бота **@clientzavod_bot** (или по адресу, который вам предоставил администратор).
2. Нажмите **Start** или отправьте `/start`.
3. В меню нажмите **🔑 Войти в аккаунт**.
4. Бот пришлёт одноразовую ссылку — нажмите на неё. Ссылка действует **10 минут**.

### 1.2 Войдите через браузер

Ссылка откроет страницу `/auth.html`. Система автоматически создаёт вашу персональную рабочую среду:
- Персональный Docker-контейнер
- Персональная база данных PostgreSQL
- Рабочее пространство `/workspace`

Инициализация занимает около **1–2 минут** при первом входе. Дождитесь завершения всех шагов.

> **Альтернативный вход:** Если вы знаете свой Telegram ID (его можно узнать через бота @userinfobot), введите его вручную на странице `/auth.html`.

## Шаг 2 — Подключение к системе модерации (CW Bot)

После входа система автоматически перенаправит вас на страницу настройки `/setup.html`.

### 2.1 Подключите CW Bot

CW Bot — это центральный бот модерации, через который вы будете получать контент на проверку перед публикацией.

1. На странице `/setup.html` нажмите кнопку **«Подключить»** в блоке «Подключение к боту».
2. Откроется Telegram-чат с CW ботом.
3. Отправьте ему **любое сообщение** (например, «привет»).
4. Бот пришлёт **6-значный код подтверждения** (действует 10 минут).

### 2.2 Введите код подтверждения

1. Вернитесь в браузер на страницу `/setup.html`.
2. Введите полученный 6-значный код в поле **«Код подтверждения»**.
3. Нажмите **«Подтвердить»**.
4. При успехе появится зелёная галочка: ✅ **Подтверждено**.

## Шаг 3 — Выбор каналов публикации

После верификации CW Bot вы увидите список доступных каналов.

### Доступные каналы

| Канал | Описание |
|---|---|
| ✅ **Telegram** | Выбран по умолчанию, обязателен |
| ВКонтакте | Публикация постов в группу VK |
| Одноклассники | Публикация в группу OK.ru |
| Pinterest | SEO-оптимизированные пины |
| Instagram | Фото-посты и Reels |
| Email | Рассылка по подписчикам |

| Facebook | Посты на страницу |
| Яндекс.Дзен | Статьи (через WordPress + RSS) |

### Как выбрать

1. Отметьте галочками каналы, в которые хотите публиковать контент.
2. Нажмите **«Сохранить и продолжить»**.
3. Система сохранит ваши настройки и перенаправит на страницу `/channels.html`.

> **Совет:** Начните с Telegram — он подключается автоматически и не требует дополнительных токенов для базового старта. Остальные каналы подключите позже.

## Шаг 4 — Настройка каналов

На странице `/channels.html` для каждого выбранного канала нужно ввести учётные данные и настроить расписание публикаций.

### Общие настройки расписания (для каждого канала)

| Параметр | Описание | Рекомендуемое значение |
|---|---|---|
| Время начала | С какого часа публиковать | 09:00 |
| Время окончания | До какого часа публиковать | 22:00 |
| Часовой пояс | Ваш часовой пояс | Europe/Moscow |
| Лимит в день | Максимум постов в сутки | 3–5 |
| Интервал публикации | Пауза между постами | 3–5 часов |
| Дни недели | В какие дни публиковать | Пн–Пт или все дни |
| Случайное время | Размазать посты по окну | Включить |
| Премодерация | Проверять контент перед публикацией | Включить (рекомендуется) |

### Настройка Telegram-канала

1. Откройте вкладку **Telegram** в `/channels.html`.
2. Введите **ID канала** (формат `-100XXXXXXXXX`).
   - Чтобы узнать ID: добавьте @userinfobot в ваш канал → отправьте любое сообщение → бот пришлёт ID.
3. Введите **Telegram ID модератора** (ваш личный ID, если модерируете сами).
4. Настройте расписание.
5. Нажмите **«Сохранить»**.

## Шаг 5 — Настройка AI-ассистента

AI-ассистент генерирует контент, анализирует темы и управляет публикацией.

### 5.1 Откройте страницу AI

Перейдите в раздел **AI** (`/ai.html`).

### 5.2 Персонализация (важно!)

Заполните файлы персонализации в вашем рабочем пространстве. Они влияют на стиль и качество генерируемого контента:

| Файл | Содержание |
|---|---|
| `IDENTITY.md` | Кто вы: имя, роль, сфера деятельности, компания |
| `SOUL.md` | Стиль общения, тон голоса, ценности бренда |
| `USER.md` | Описание целевой аудитории, её интересы и боли |
| `MEMORY.md` | Важные ссылки, ключевые факты, контекст |

> **Как редактировать:** Перейдите в раздел **Файлы** (`/files.html`), найдите файлы в корне `/workspace` и нажмите «Редактировать».

### 5.3 Настройка AI-провайдера

Если у вас есть собственный API-ключ:
1. В разделе AI выберите провайдера: **OpenAI**, **OpenRouter** или **ProTalk**.
2. Введите API-ключ.
3. Выберите модель (рекомендуется: `gpt-4o` или `claude-3-5-sonnet`).
4. Нажмите **«Сохранить»**.

## Шаг 6 — Загрузка тем и материалов

Для генерации контента системе нужны темы (о чём писать) и, опционально, фото товаров.

### 6.1 Добавление тем

**Вариант А — Через веб-интерфейс:**
1. Перейдите в раздел **Контент** (`/content.html`).
2. Нажмите **«Добавить тему»**.
3. Введите тему и, при необходимости, укажите для какого канала она предназначена.

**Вариант Б — Импорт из Google Sheets:**
1. В разделе **Контент** нажмите **«Импорт из таблицы»**.
2. Вставьте ссылку на Google Sheets.
3. Укажите колонки: тема, описание, канал.
4. Нажмите **«Импортировать»**.

**Формат таблицы для импорта:**
| topic | description | channel |
|---|---|---|
| Название темы | Подробное описание | telegram |
| Другая тема | Описание | vk |

> **Универсальные темы:** Если поле `channel` оставить пустым, тема будет доступна всем каналам.

### 6.2 Загрузка фото товаров (для видео-пайплайна)

Если вы планируете публиковать видео в TikTok, VK Video, Instagram Reels или YouTube:

1. Перейдите в раздел **Файлы** (`/files.html`).
2. Откройте папку `/workspace/input/`.
3. Загрузите фотографии товаров (форматы JPG, PNG).

Система автоматически использует эти фото для генерации видео через AI (KIE.ai).

## Шаг 7 — Запуск публикации

### 7.1 Сгенерируйте первый контент

**Через AI-чат:**
1. Перейдите в раздел **AI** (`/ai.html`).
2. Напишите запрос, например: *«Сгенерируй 5 постов для нашего Telegram-канала на основе тем из базы»*.
3. AI создаст черновики и поставит их в очередь.

**Автоматически по расписанию:**
- Система сама проверяет темы и генерирует контент каждые 60 секунд.
- Новый контент появляется в разделе **Контент** → вкладка **Очередь**.

### 7.2 Модерация (если включена премодерация)

1. Когда контент готов, CW Bot пришлёт вам сообщение в Telegram с превью.
2. Доступные действия:
   - ✅ **Одобрить** — контент уйдёт в очередь на публикацию
   - 🔁 **Перегенерировать** — AI создаст новый вариант
   - ❌ **Отклонить** — черновик удаляется, тема освобождается
3. Одобренный контент автоматически публикуется в указанное по расписанию время.

### 7.3 Мониторинг

- **Контент** (`/content.html`) — список черновиков, очередь, история публикаций.
- **Аналитика** — статистика публикаций по каналам.
- **Логи** — детальный лог каждой операции.

## Оптимальный путь (минимум действий)

Чтобы запустить публикацию в Telegram за минимальное число шагов:

```
1. Telegram Auth Bot → /start → 🔑 Войти → получить ссылку
   ↓ (1 минута)
2. Перейти по ссылке в браузере → дождаться инициализации (1-2 мин)
   ↓
3. setup.html → нажать "Подключить" → открыть CW Bot → отправить сообщение
   → скопировать 6-значный код → вставить в форму → "Подтвердить"
   ↓ (2 минуты)
4. Выбрать каналы → нажать "Сохранить и продолжить"
   ↓
5. channels.html → Telegram → ввести ID канала → ввести ID модератора → Сохранить
   ↓ (1 минута)
6. content.html → Добавить тему → написать тему → Сохранить
   ↓
7. Готово! Система начнёт генерацию. Ожидайте сообщение от CW Bot для модерации.
```

**Итого: ~5–7 минут** до получения первого контента на модерацию.

## Настройка каждого канала: подробности

### Telegram

**Как получить ID канала:**
1. Добавьте бота @userinfobot как администратора в ваш канал.
2. Отправьте любое сообщение в канал.
3. @userinfobot пришлёт ID в формате `-100XXXXXXXXX`.
4. Удалите @userinfobot из канала после получения ID.

**Как добавить CW Bot в канал:**
1. Зайдите в настройки вашего Telegram-канала.
2. Добавьте бота-модератора (@clientzavod_cw_bot или аналог) как **администратора**.
3. Предоставьте права: публикация сообщений.

---

### ВКонтакте (VK)

**Как получить токен VK:**
1. Перейдите на [vk.com/dev](https://vk.com/dev) → создайте Standalone-приложение.
2. Получите access token с правами: `wall`, `photos`, `groups`, `offline`.
3. Укажите ID группы (число в URL вашего сообщества, со знаком минус: `-XXXXXXX`).

**VK Video** настраивается отдельно. Видео генерируется автоматически из фото товаров в `/workspace/input/`.

---

### Instagram

**Через Buffer API** (так же, как Pinterest и YouTube):
1. Зарегистрируйтесь на [buffer.com](https://buffer.com).
2. Подключите Instagram-аккаунт в Buffer.
3. Получите API-токен в настройках Buffer → Developers.
4. В форме канала Instagram введите токен и нажмите **«Загрузить каналы»**.
5. Выберите канал Instagram из выпадающего списка.
6. Нажмите **«Сохранить»**.

---

### Pinterest

**Через Buffer API:**
1. Зарегистрируйтесь на [buffer.com](https://buffer.com).
2. Подключите Pinterest-аккаунт в Buffer.
3. Получите API-токен в настройках Buffer → Developers.
4. В форме канала введите токен и нажмите **«Загрузить каналы»**.
5. Выберите канал Pinterest из выпадающего списка.
6. Нажмите **«Загрузить доски»** → выберите нужную доску.
7. Введите URL вашего сайта (будет прикрепляться к каждому пину).

---

### YouTube

**Через Buffer API:**
1. Подключите YouTube-канал в Buffer.
2. Получите токен Buffer API (те же шаги, что для Pinterest).
3. В форме канала YouTube введите токен → **«Загрузить каналы»** → выберите YouTube.

---

### TikTok

1. Введите учётные данные TikTok в форме канала.
2. Загрузите фото товаров в `/workspace/input/` — система сгенерирует видео автоматически.
3. Видео проходит модерацию через CW Bot (кнопки `tt_mod:`).

---

### WordPress / Яндекс.Дзен

1. Введите URL вашего WordPress-блога (формат: `https://yourdomain.com`).
2. Введите логин WordPress.
3. Создайте **Application Password** в WordPress (Пользователи → Ваш профиль → Application Passwords).
4. Введите Application Password в форму.
5. Яндекс.Дзен получает контент автоматически через RSS вашего WordPress.

---

### Email

1. Введите IMAP-данные для получения писем (хост, порт, логин, пароль).
2. Введите SMTP-данные для отправки (хост, порт, логин, пароль).
3. Система будет автоматически обрабатывать входящие письма и отправлять рассылки.

## Часто задаваемые вопросы

**Q: Код подтверждения истёк, что делать?**
A: Снова отправьте сообщение CW Боту — он пришлёт новый код. Код действует 10 минут.

**Q: Как узнать свой Telegram ID?**
A: Напишите боту @userinfobot в Telegram — он пришлёт ваш ID.

**Q: Контент генерируется, но не публикуется. Почему?**
A: Проверьте:
1. Включена ли премодерация — если да, дождитесь одобрения в CW Bot.
2. Наступило ли запланированное время публикации.
3. Не превышен ли дневной лимит публикаций.
4. Добавлен ли CW Bot как администратор в ваш Telegram-канал.

**Q: Как отключить модерацию для полностью автоматической публикации?**
A: В настройках канала снимите галочку **«Премодерация»**. После этого одобренный AI контент будет публиковаться автоматически без вашего участия.

**Q: Можно ли публиковать разный контент в разные каналы?**
A: Да. При добавлении темы укажите поле `channel` — тогда эта тема будет доступна только указанному каналу. Темы без указания канала считаются универсальными.

**Q: Как загрузить много тем сразу?**
A: Создайте Google Таблицу с колонками `topic`, `description`, `channel` и воспользуйтесь функцией импорта в разделе **Контент**.

**Q: Где посмотреть историю публикаций?**
A: Раздел **Контент** (`/content.html`) → вкладка **История**. Там отображаются все опубликованные материалы с датой, каналом и статусом.

**Q: Как изменить расписание публикаций?**
A: Перейдите в **Каналы** (`/channels.html`), выберите нужный канал и измените параметры расписания. Изменения применяются сразу.

**Q: Видео не генерируется. Что проверить?**
A: Убедитесь, что в папке `/workspace/input/` есть хотя бы одно фото товара (JPG или PNG). Без фото видео-пайплайн не запускается.

**Q: Как добавить нового пользователя?**
A: Каждый новый пользователь проходит онбординг самостоятельно через Auth Bot. Администратор может управлять пользователями через `/admin/containers.html`.
