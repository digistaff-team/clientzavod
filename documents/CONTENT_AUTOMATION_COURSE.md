# 📚 Учебный курс: Автоматизация контента в социальных сетях с платформой «Клиент Завод»

## Описание курса

**Цель:** Научить пользователей с нулевым уровнем подготовки создавать и публиковать качественный контент в социальных сетях с помощью AI-агента.

**Формат:** Самообучение + практические задания  
**Продолжительность:** 2-3 недели (4-6 часов в неделю)  
**Уровень:** Начальный (не требует технических навыков)

---

## 📋 Структура курса

### Модуль 1. Введение в платформу (День 1-2)

#### Урок 1.1. Что такое «Клиент Завод» и зачем он нужен

**Цели:**
- Понять возможности платформы
- Узнать, какие задачи можно автоматизировать

**Содержание:**
- Что такое AI-агент и как он помогает
- Какие соцсети поддерживаются (Telegram, VK, OK, Pinterest)
- Примеры использования:
  - Автопостинг контента по расписанию
  - Генерация текстов и изображений через AI
  - Публикация в несколько каналов одновременно

**Практика:**
- Зарегистрироваться в системе
- Изучить главный экран веб-интерфейса

---

#### Урок 1.2. Первый вход и настройка профиля

**Цели:**
- Научиться входить в систему
- Создать персональный контейнер

**Содержание:**
- Вход через Telegram ID (без пароля)
- Что такое персональный контейнер (ваше изолированное пространство)
- Как работает ожидание подготовки окружения (1-2 минуты)

**Практика:**
1. Открыть `https://claw.pro-talk.ru`
2. Ввести свой Telegram ID
3. Дождаться подготовки контейнера
4. Проверить раздел **«Файлы»** — должны быть папки `input`, `output`, `work`

**Контрольный вопрос:**
> Сколько времени занимает первая подготовка контейнера?
> - а) 5 секунд
> - б) 1-2 минуты ✓
> - в) 10 минут

### Модуль 2. Настройка каналов публикации (День 3-5)

#### Урок 2.1. Подключение Telegram-канала

**Цели:**
- Создать Telegram-канал
- Добавить бота в канал
- Настроить публикацию

**Содержание:**
- Как создать канал в Telegram
- Как добавить бота @clientzavod_bot в канал
- Права доступа для бота (администратор)

**Практика:**
1. Создать канал в Telegram
2. Добавить @clientzavod_bot как администратора
3. В веб-интерфейсе перейти в **«Каналы»** → **Telegram**
4. Вставить токен бота (получить у администратора)
5. Нажать **«Сохранить»**

**Чек-лист успешной настройки:**
- [ ] Бот отображается в списке участников канала
- [ ] В веб-интерфейсе статус «Подключено»

---

#### Урок 2.2. Подключение ВКонтакте

**Цели:**
- Создать сообщество VK
- Получить доступ к API

**Содержание:**
- Типы сообществ VK (публичная страница, группа)
- Как получить токен доступа
- Настройки приложения VK

**Практика:**
1. Создать сообщество ВКонтакте
2. Перейти в [разработчикам VK](https://vk.com/dev)
3. Создать приложение типа «Standalone»
4. Скопировать `App ID`, `Secret Key`, `Access Token`
5. Ввести данные в разделе **«Каналы»** → **VK**

---

#### Урок 2.3. Подключение Одноклассников и Pinterest

**Цели:**
- Настроить публикацию в OK и Pinterest

**Содержание:**
- Особенности публикации в OK (требует модерации)
- Pinterest как источник трафика

**Практика:**
- Повторить шаги из Урока 2.2 для OK и Pinterest
- Использовать готовые ключи из `.env.example` (для обучения)

### Модуль 3. Работа с файлами и материалами (День 6-8)

#### Урок 3.1. Загрузка файлов в контейнер

**Цели:**
- Научиться загружать файлы через веб-интерфейс
- Понять структуру папок

**Содержание:**
- Папка `input/` — входные данные (изображения, описания)
- Папка `output/` — готовые результаты
- Папка `work/` — рабочие файлы

**Практика:**
1. Перейти в раздел **«Файлы»**
2. Перетащить изображение в зону загрузки
3. Проверить, что файл появился в папке `input`
4. Скачать файл обратно для проверки

**Задание:**
> Загрузите 3 изображения в папку `input` и одно текстовое описание (файл `.txt`)

---

#### Урок 3.2. Использование загруженных файлов для генерации

**Цели:**
- Научиться использовать файлы как референс для AI

**Содержание:**
- Как AI читает файлы из `input/`
- Текстовые файлы с описанием стиля
- Изображения как визуальный референс

**Практика:**
1. Создать файл `image-prompt.txt` с описанием:
   ```
   Создай изображение в стиле ар-деко с золотыми элементами.
   Тема: деловой успех, рост, процветание.
   ```
2. Загрузить в `input/`
3. При генерации контента файл будет использован автоматически

### Модуль 4. Создание контента с AI (День 9-12)

#### Урок 4.1. Настройка AI-агента

**Цели:**
- Подключить AI-модель
- Настроить параметры генерации

**Содержание:**
- Что такое Bot ID и Bot Token (ProTalk)
- Выбор модели (GPT-4o, GPT-4o-mini)
- Проверка баланса токенов

**Практика:**
1. Перейти в раздел **«ИИ»**
2. Ввести Bot ID и Bot Token (выдаются преподавателем)
3. Выбрать модель `gpt-4o-mini` (экономная)
4. Нажать **«Сохранить»**
5. Проверить баланс токенов

---

#### Урок 4.2. Генерация текста поста

**Цели:**
- Создать тему поста
- Сгенерировать текст через AI

**Содержание:**
- Структура темы: фокусный ключ, вторичные ключи, LSI
- Как AI использует материалы из базы

**Практика:**
1. Перейти в раздел **«Контент»**
2. Нажать **«Добавить тему»**
3. Заполнить:
   - Тема: «Как автоматизировать контент»
   - Фокусный ключ: `автоматизация контента`
   - Вторичные: `SMM, постинг, AI`
4. Нажать **«Сгенерировать пост»**
5. Проверить результат в черновиках

---

#### Урок 4.3. Генерация изображений

**Цели:**
- Настроить генерацию изображений
- Использовать файлы из `input/`

**Содержание:**
- Kie.ai API для генерации
- Как файлы из `input/` влияют на промпт
- Настройки стиля (по умолчанию: marble & gold)

**Практика:**
1. Убедиться, что в `input/` есть файл описания
2. В разделе **«Контент»** выбрать тему
3. Нажать **«Сгенерировать изображение»**
4. Дождаться результата (до 90 секунд)
5. Проверить изображение в `output/content/`

---

#### Урок 4.4. Генерация видео (опционально)

**Цели:**
- Настроить генерацию видео
- Понять ограничения

**Содержание:**
- Видео-провайдеры: RunwayML, Pika
- Таймаут генерации (5 минут)
- Fallback на изображение при ошибке

**Практика:**
1. В настройках выбрать `CONTENT_MVP_CONTENT_TYPE=text+video`
2. Повторить шаги из Урока 4.3
3. Проверить видео в `output/content/`

---

### Модуль 5. Публикация и планирование (День 13-16)

#### Урок 5.1. Ручная публикация

**Цели:**
- Опубликовать пост вручную
- Проверить результат в соцсети

**Содержание:**
- Черновики и премодерация
- Как бот отправляет пост на модерацию
- Публикация после одобрения

**Практика:**
1. В разделе **«Контент»** выбрать готовый черновик
2. Нажать **«Опубликовать»**
3. Проверить канал Telegram — пост должен появиться

---

#### Урок 5.2. Настройка расписания

**Цели:**
- Настроить автопубликацию по расписанию
- Задать время и дни недели

**Содержание:**
- Формат времени `HH:MM` (например, `09:00`)
- Дни недели (Пн-Пт, Пн-Вс)
- Часовой пояс (Europe/Moscow)

**Практика:**
1. В разделе **«Контент»** → **Настройки**
2. Установить:
   - Время: `09:00`
   - Часовой пояс: `Europe/Moscow`
   - Дни: Пн, Ср, Пт
3. Сохранить

---

#### Урок 5.3. Лимиты и квоты

**Цели:**
- Понять систему лимитов
- Избежать блокировок

**Содержание:**
- Дневные лимиты (по умолчанию: 1 пост/день)
- Лимиты токенов для AI
- Как увеличить лимиты

**Практика:**
- Проверить текущие лимиты в разделе **«Контент»** → **Настройки**
- Запросить увеличение у администратора (если нужно)

---

### Модуль 6. Продвинутые техники (День 17-20)

#### Урок 6.1. Импорт тем из Google Таблиц

**Цели:**
- Настроить импорт из Google Sheets
- Массовое создание тем

**Содержание:**
- Формат таблицы (колонки: тема, ключи, статус)
- Настройки доступа («Все, у кого есть ссылка»)

**Практика:**
1. Создать Google Таблицу с колонками:
   ```
   Тема | Фокусный ключ | Вторичные ключи | Статус
   ```
2. Заполнить 5-10 темами
3. В разделе **«Контент»** нажать **«Импорт из Google Sheets»**
4. Вставить ссылку
5. Проверить, что темы появились в списке

---

#### Урок 6.2. Работа с черновиками и редакция

**Цели:**
- Редактировать сгенерированные тексты
- Перегенерировать часть контента

**Содержание:**
- Как отредактировать текст перед публикацией
- Перегенерация изображения без изменения текста

**Практика:**
1. Открыть черновик
2. Нажать **«Редактировать текст»**
3. Внести правки
4. Нажать **«Перегенерировать изображение»**
5. Сохранить изменения

---

#### Урок 6.3. Мультиканальная публикация

**Цели:**
- Публиковать в несколько каналов одновременно
- Настроить разные форматы для разных платформ

**Содержание:**
- Адаптация контента под платформу
- VK: длинные тексты + изображения
- OK: умеренный тон
- Pinterest: визуальный акцент

**Практика:**
1. Подключить 2+ канала (Telegram + VK)
2. Создать пост
3. Выбрать оба канала для публикации
4. Проверить результат в обеих соцсетях

---

### Модуль 7. Финальный проект (День 21-28)

#### Урок 7.1. Создание контент-плана на неделю

**Задание:**
1. Создать 7 тем (по одной на день)
2. Для каждой темы:
   - Сгенерировать текст
   - Сгенерировать изображение
   - Добавить хэштеги
3. Настроить расписание на неделю
4. Опубликовать первые 3 поста

**Критерии оценки:**
- [ ] 7 тем создано и заполнено
- [ ] Все посты с изображениями
- [ ] Расписание настроено
- [ ] 3 поста опубликовано успешно

---

#### Урок 7.2. Анализ результатов

**Задание:**
1. Проверить статистику публикаций:
   - Просмотры
   - Реакции
   - Комментарии
2. Записать выводы:
   - Какие темы работают лучше
   - Какие изображения получают больше реакций
3. Скорректировать контент-план на следующую неделю

## 📚 Дополнительные материалы

### Глоссарий

| Термин | Определение |
|--------|-------------|
| **AI-агент** | Автономная программа, которая принимает решения и выполняет задачи |
| **Контейнер** | Изолированное пространство для ваших файлов и задач |
| **Токены** | Единицы измерения расхода AI-запросов (текст/изображения) |
| **Черновик** | Неопубликованный пост на премодерации |
| **Webhook** | URL для автоматической отправки данных в систему |

### Частые ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Недостаточно токенов» | Баланс исчерпан | Пополнить в разделе «Баланс» |
| «Бот не отвечает» | Неправильный токен | Проверить токен в настройках |
| «Изображение не генерируется» | Ошибка Kie.ai | Повторить через 5 минут |
| «Пост не опубликован» | Нет прав у бота | Дать боту права администратора |
