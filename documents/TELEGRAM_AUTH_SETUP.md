# Настройка авторизации через Telegram-бота

## Обзор

Система авторизации позволяет пользователям входить в приложение двумя способами:

1. **Через Telegram-бота** — пользователь переходит по ссылке в бота @DigiStaff_Team_bot и нажимает кнопку "Войти в аккаунт"
2. **По Telegram ID** — пользователь вводит свой Telegram ID на сайте

## Настройка

### 1. Создание Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 2. Переменные окружения

Добавьте в `.env` файл или переменные окружения:

```env
# Токен главного бота авторизации
AUTH_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# URL API (для формирования ссылок редиректа)
API_URL=https://claw.pro-talk.ru
```

### 3. Запуск

При запуске сервера auth-бот автоматически запустится, если указан `AUTH_BOT_TOKEN`:

```bash
node server.js
```

В логах вы увидите:
```
🤖 Auth bot: ✅ STARTED (@DigiStaff_Team_bot)
```

## API Endpoints

### POST /api/auth/telegram-login

Авторизация при нажатии кнопки в Telegram-боте.

**Request:**
```json
{
  "telegram_id": "123456789",
  "username": "@username"
}
```

**Response (успех):**
```json
{
  "success": true,
  "chatId": "123456789",
  "username": "@username",
  "verified": true,
  "hasBot": false,
  "hasAI": false,
  "sessionActive": true,
  "isNewUser": true,
  "redirectUrl": "https://claw.pro-talk.ru/?chat_id=123456789",
  "message": "Аккаунт создан и авторизован"
}
```

### POST /api/auth/by-telegram-id

Вход по Telegram ID (вводится вручную на сайте).

**Request:**
```json
{
  "telegram_id": "123456789"
}
```

**Response (успех):**
```json
{
  "success": true,
  "chatId": "123456789",
  "username": "@username",
  "verified": true,
  "hasBot": false,
  "hasAI": false,
  "redirectUrl": "https://claw.pro-talk.ru/?chat_id=123456789",
  "message": "Вход выполнен"
}
```

**Response (пользователь не найден):**
```json
{
  "success": false,
  "error": "Пользователь с таким Telegram ID не найден.",
  "needRegister": true,
  "botLink": "https://t.me/DigiStaff_Team_bot",
  "message": "Перейдите в бота и нажмите \"Войти в аккаунт\" для создания аккаунта."
}
```

### GET /api/auth/check?telegram_id=123456789

Проверка авторизации по Telegram ID.

**Response:**
```json
{
  "authorized": true,
  "chatId": "123456789",
  "username": "@username",
  "verified": true,
  "hasBot": false,
  "sessionActive": true,
  "containerId": "abc123..."
}
```

### GET /api/auth/telegram-info?telegram_id=123456789

Получение информации о пользователе.

**Response:**
```json

  "found": true,

  "username": "@username",
  "verified": true,
  "hasBot": false,
  "hasAI": false,
```

## Команды Telegram-бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и кнопка входа |
| `/login` | Кнопка входа в аккаунт |
| `/help` | Справка по боту |
| `/id` | Показать Telegram ID пользователя |

## Обработка ошибок

### Пользователь не найден

Если пользователь пытается войти по Telegram ID, которого нет в системе:

1. Возвращается ошибка с `needRegister: true`
2. Предлагается перейти в бота для создания аккаунта
3. При переходе в бот и нажатии кнопки "Войти" — аккаунт создаётся автоматически

### Ошибки сети

При ошибках соединения:
- В веб-интерфейсе показывается уведомление "Ошибка сети"
- В боте показывается сообщение "Ошибка соединения с сервером"

## Безопасность

1. **Telegram ID** — уникальный идентификатор пользователя в Telegram
2. **Автоматическая верификация** — при входе через бот пользователь автоматически верифицируется
3. **Создание сессии** — при первом входе создаётся Docker-контейнер пользователя
4. **Персистентность** — данные сохраняются в `manage-state-{chatId}.json`
